DE-BUFF PARTY / PUBLIC GAME OVERVIEW

GAME
GUIDE.

De-buff Party is a four-player, co-located Mixed Reality experience built around shared activities, communication, decision-making and collaboration in the same physical space.

No prior knowledge is required.

This public guide provides only a high-level overview. All detailed gameplay instructions are given to every participant during the same standardised pre-experiment briefing.
